# GIP road snapshots

Place the annual GIP exports here as `2015.osm.pbf` through `2025.osm.pbf`.

These files are the road-network source for Valhalla graph construction, motorway-exit destinations, and GIP figures. The `.osm.pbf` suffix describes the exchange format; the source is GIP, not OpenStreetMap. PBF files are intentionally excluded from Git.
